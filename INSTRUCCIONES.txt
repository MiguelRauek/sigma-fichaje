SIGMAFICHAJE — PASOS EN TEXTO
=============================

La versión con botones para copiar está en:
https://miguelrauek.github.io/sigma-fichaje/instrucciones.html

Ábrela en el navegador del móvil: cada paso tiene su botón de copiar.


HORARIOS
--------
   Entrada:  entre 10:06:00 y 10:09:59  (segundo al azar, nunca en punto)
   Salida :  entre 18:06:00 y 18:09:59  (segundo al azar, nunca en punto)
   Hasta el 25/10/2026, incluido. Ese día ficha y se apaga.


1. Instalar Termux y Termux:API (desde F-Droid, no desde la Play Store).
   La app Termux:API es obligatoria para la alarma.

2. Instalar Termux:Boot (también desde F-Droid).

3. Instalar el paquete de comandos DENTRO de Termux (imprescindible):

   pkg install termux-api

   Trae el reloj que programa los fichajes y la alarma. Si falta esto,
   el programa NO ficha y no suena la alarma.

4. Crear config.json con tus credenciales de sigmatime.es:

   nano ~/config.json

   {
     "email": "TU-CORREO",
     "pass": "TU-CONTRASENA"
   }

   OJO: la clave se llama "pass", no "password". Guardar con CTRL+O y
   salir con CTRL+X.

5. Permisos en el móvil (Termux y Termux:Boot):
   - Batería: Sin restricciones
   - Ejecución en 2º plano: Permitir
   - Inicio automático: Permitir
   - Notificaciones: activadas

6. Descargar los tres ficheros:

   curl -fsSL -o sigma_punch.py https://raw.githubusercontent.com/MiguelRauek/sigma-fichaje/main/sigma_punch.py
   curl -fsSL -o reloj.sh        https://raw.githubusercontent.com/MiguelRauek/sigma-fichaje/main/reloj.sh
   curl -fsSL -o sigma_boot.sh   https://raw.githubusercontent.com/MiguelRauek/sigma-fichaje/main/sigma_boot.sh

7. Colocar el reloj y crear el arranque automático:

   mkdir -p ~/bin ~/.termux/boot
   mv reloj.sh ~/bin/reloj.sh
   cp sigma_boot.sh ~/.termux/boot/sigma.sh
   chmod +x ~/bin/reloj.sh ~/.termux/boot/sigma.sh
   cat ~/.termux/boot/sigma.sh

   Debe mostrar --period-ms 900000 y ~/bin/reloj.sh.

8. Reiniciar el móvil. El arranque solo programa el reloj y se apaga:
   no mantiene el móvil despierto. El candado se toma únicamente durante
   el fichaje, unos minutos al día.


COMPROBAR QUE ESTÁ FUNCIONANDO
------------------------------

Ver que el reloj late (una línea cada 15 minutos):

  tail -5 ~/fichaje_boot.log

Probar login y portal SIN fichar nada:

  python sigma_punch.py --check

Ver los fichajes que hay ahora mismo en la web, sin fichar nada:

  python sigma_punch.py --ver

Ver el log de hoy:

  grep "$(date +%F)" fichaje.log

Lo bueno es ver líneas "intento" y luego "OK".


SI SUENA LA ALARMA
------------------

Suena cuando el fichaje falla por falta de internet: el tono de alarma del
móvil en bucle, dos veces, y un cartel en pantalla. Es para enterarte el
mismo día, no al siguiente.

Si el fallo es de la web y no de internet, solo sale el cartel, sin ruido.
