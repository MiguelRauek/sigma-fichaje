PASOS PARA EL FICHAJE AUTOMATICO (Termux en el movil)
=====================================================

1) INSTALAR PAQUETES (una sola vez):
   pkg update -y && pkg install python cronie termux-services tzdata -y

2) DESCARGAR EL SCRIPT (navegador del movil, con tu cuenta de GitHub iniciada):
   Abre: https://github.com/MiguelRauek/sigma-fichaje/raw/refs/heads/main/sigma_punch.py
   Menu (3 puntos) -> Descargar
   Luego en Termux:
   cp /sdcard/Download/sigma_punch.py ~/

3) CREDENCIALES (cambia TU_EMAIL y TU_PASS por las de sigmatime.es):
   echo '{"email": "TU_EMAIL", "pass": "TU_PASS"}' > config.json

4) PROBAR (no ficha nada):
   python sigma_punch.py --check
   Debe salir: [Check] OK - login OK - c_usu=... - fichajes de hoy: N

5) PROGRAMAR (entrada 9:30, salida 17:55):
   sv-enable crond
   echo "30 9 * * * python /data/data/com.termux/files/home/sigma_punch.py --entry >> /data/data/com.termux/files/home/fichaje.log 2>&1" > crontab.txt
   echo "55 17 * * * python /data/data/com.termux/files/home/sigma_punch.py --exit >> /data/data/com.termux/files/home/fichaje.log 2>&1" >> crontab.txt
   crontab crontab.txt
   crontab -l

6) QUE ANDROID NO LO MATE:
   Ajustes -> Apps -> Termux -> Bateria -> Sin restricciones
   Deja Termux en segundo plano (bloquealo en recientes).

COMPROBAR AL DIA SIGUIENTE:
   cat fichaje.log
